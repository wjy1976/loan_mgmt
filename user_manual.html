借貸管理系統使用說明書

本說明書將引導您快速掌握借貸管理系統的各項功能，讓您能有效率地管理所有借貸案件。

閱讀時間：約15分鐘
最後更新：2026年1月
版本：2.026.0101

快速開始

系統兩種模式

本系統提供兩種使用模式：正式模式（需註冊登入，資料儲存於雲端）和試用模式（免登入，資料僅存於瀏覽器）。建議正式使用前先試用熟悉操作。

1

註冊與登入

首次使用請點擊「註冊新帳號」建立您的專屬帳號：

  • 輸入帳號ID（用於登入的用戶名稱）
  • 輸入綁定Email（系統認證用）
  • 設定密碼並確認

請務必記住您的帳號ID和密碼，系統使用Email+密碼認證，但登入時使用帳號ID。

2

試用模式體驗

如果不確定是否適合，可以先使用試用模式：

試用模式優點
  • • 免註冊立即使用
  • • 內建範例資料
  • • 完整功能體驗
試用模式限制
  • • 資料不儲存於雲端
  • • 關閉瀏覽器後資料消失
  • • 無法多人協作
3

新增第一筆案件

登入後，按照以下步驟新增您的第一筆借貸案件：

  1. 點擊左側選單「案件列表」
  2. 點擊右上角「新增」按鈕
  3. 填寫借款人基本資料
  4. 設定貸款金額與條件
  5. 選擇適當的案件狀態
  6. 點擊「儲存資料」完成

儀表板操作

儀表板是系統的核心，提供即時財務數據和案件狀態總覽。所有數據卡片都可以自定義調整。

財務卡片說明

總收入 (累計)

所有案件累計已收到的利息收入總和

淨收入

總收入扣除呆帳金額後的淨收益

債權總額

尚未收回的借款總額（狀態1+3+5欠款總和）

目前放款額

當前放款的總額度（狀態1+3+5借款金額總和）

卡片自定義功能

拖放調整位置

直接拖放卡片到您喜歡的位置，系統會自動記住您的設定。

變更卡片顏色

點擊卡片右上角的調色盤圖示，循環切換6種顏色主題。

調整卡片大小

點擊卡片右上角的最大化/最小化圖示，切換1欄或2欄寬度。

使用小技巧

點擊任何財務卡片，可以直接查看該指標的詳細案件列表。例如點擊「本月應收款」卡片，會顯示所有本月應收款的案件明細。

協商案件（狀態5）

協商案件是借款人因故無法按原條件還款，經雙方協商後的新還款方案：

  • 每月固定還款協商本金，無利息
  • 需在新增/編輯案件時設定「協商本金」欄位
  • 本金欄位顯示為「協商:$金額」，利息欄位顯示0
  • 還款日程僅記錄本金還款

協商案件同樣會計入債權總額和呆帳金額統計中。

批次刪除功能

安全批次刪除案件

當需要清理大量無效案件時，可以使用批次刪除功能：

1
點擊「批次刪除」按鈕進入批次模式
2
勾選要刪除的案件（可「全選本頁」）
3
點擊「刪除選取案件」
4
系統顯示確認訊息，列出前5筆案件
5
確認後永久刪除，無法復原

批次刪除是永久性操作，刪除後無法恢復，請謹慎使用。

還款入帳

還款入帳流程

1. 搜尋未繳案件

在還款入帳頁面，系統會自動篩選出所有未繳案件。您可以：

  • 直接從下拉選單選擇案件
  • 輸入編號或姓名搜尋未繳案件
  • 搜尋結果會標示「此案件本月尚未繳款」

2. 輸入還款資訊

選擇案件後，系統會自動帶入應還金額：

  • 還款日期：預設為今天，可修改
  • 還款本金：系統自動帶入，可調整
  • 還款利息：系統自動帶入，可調整
  • 協商案件只顯示本金欄位（利息為0）

3. 確認入帳

輸入完成後點擊「確認入帳」：

  • 系統會將還款記錄加入該案件的還款日程
  • 財務指標會即時更新
  • 案件的本月繳款狀態變更為「已繳清」
  • 系統顯示成功訊息

快捷還款技巧

在案件列表頁面，直接點擊案件的「本月繳款狀態」欄位（綠色「已繳清」或紅色「未繳」文字）， 系統會自動跳轉到還款入帳頁面並選擇該案件，節省搜尋時間。

試試看：在案件列表點擊任何案件的繳款狀態文字

資料匯入匯出

CSV匯出功能

垂直格式報表匯出

系統採用垂直格式（欄位為列，案件為欄）匯出CSV，這種格式更容易閱讀和比對。

匯出步驟：
  1. 在案件列表頁面，使用篩選或搜尋功能找到要匯出的案件
  2. 點擊「匯出 CSV」按鈕
  3. 系統會產生檔名為「借貸管理資料_垂直格式_日期.csv」的檔案
  4. 檔案會自動下載到您的電腦
檔案格式說明：
  • 第一列為欄位名稱（編號、狀態、借款人等）
  • 第一欄為案件1的資料，第二欄為案件2的資料，依此類推
  • 包含還款日程資訊
  • 使用Big5編碼，可用Excel開啟

CSV匯入功能

批次匯入案件資料

可將外部資料或備份資料匯入系統，節逐一新增案件的時間。

重要注意事項
  • • 匯入功能僅在登入後可用（試用模式無法匯入）
  • • 檔案必須為CSV格式，Big5編碼
  • • 建議先匯出現有資料了解格式
  • • 匯入前建議先備份現有資料
匯入步驟：
  1. 準備符合格式的CSV檔案（建議用匯出的檔案作為範本）
  2. 在案件列表頁面，點擊「匯入 CSV」按鈕
  3. 選擇要匯入的檔案
  4. 系統會解析檔案並顯示處理進度
  5. 匯入成功後會顯示新增案件數量
匯入格式提示

匯入檔案需包含以下基本欄位：狀態、方式、借款人、借款金額、放款日期。其他欄位可為空值。

離線使用提醒

手機版同樣支援離線操作（試用模式），但正式模式需要網路連線才能同步資料到雲端。 建議在網路穩定的環境下使用正式模式，以確保資料同步。

常見問題

請按照以下步驟檢查：

  1. 確認帳號ID和密碼正確（注意大小寫）
  2. 確認網路連線正常
  3. 如果是第一次使用，請先註冊新帳號
  4. 如忘記密碼，請聯絡系統管理員重設

系統使用帳號ID+密碼認證，但實際綁定的是Email。請確認輸入的帳號ID正確。

可能的原因和解決方法：

  • 試用模式：確認您不是使用試用模式（試用模式資料不儲存到雲端）
  • 網路問題：檢查網路連線是否正常
  • 登入狀態：確認您已成功登入（右上角顯示您的帳號）
  • 重新整理：重新整理頁面查看資料是否恢復

試用模式的資料僅存在瀏覽器記憶體中，關閉瀏覽器或清除快取後會消失。

匯入失敗的常見原因：

  • 檔案格式：確認檔案為CSV格式，副檔名為.csv
  • 檔案編碼：確認檔案使用Big5編碼（可用記事本另存新檔選擇編碼）
  • 必填欄位：確認包含必填欄位（借款人、借款金額、狀態）
  • 登入狀態：確認已登入（試用模式無法匯入）

建議先匯出一份現有資料，了解正確格式後再準備匯入檔案。

建議定期備份資料，方法如下：

  1. 定期匯出：每月使用「匯出 CSV」功能備份所有案件
  2. 多重備份：保留至少3個時間點的備份檔案
  3. 異地備份：將備份檔案儲存於不同位置（電腦、雲端硬碟、隨身碟）
  4. 測試還原：定期測試備份檔案能否成功匯入

雖然系統資料儲存於雲端，但養成定期備份習慣可避免意外資料損失。

設定協商案件的步驟：

  1. 新增或編輯案件時，選擇狀態為「5 - 協商中」
  2. 系統會自動清空期數和利息相關欄位
  3. 在「協商本金」欄位輸入每期還款金額
  4. 其他欄位按正常案件填寫
  5. 儲存後，案件會顯示為紫色，本金欄位顯示「協商:$金額」

協商案件每月固定還款本金，無利息。還款入帳時只需輸入本金，利息欄位自動為0。
